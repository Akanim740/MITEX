Code Playground

Write and run Python and C++ right in your browser. Both engines execute locally, so your code never leaves the page.



      

        Python runs on Pyodide (CPython in WebAssembly). C++ runs on the JSCPP interpreter, which covers variables, functions, loops, arrays, pointers and iostream — but not classes, namespaces or the full standard library.
        Python: input() is not supported yet — use print. C++: cin reads from the input box above.
        Both engines are downloaded once from a public CDN on first run. Infinite loops freeze the tab, so keep them finite. Code is kept in this browser only.
